# Noted

Notes with labels, colours, checklists, reminders and attachments, on iOS,
Android and the web. Notes live on the device first and synchronise when there
is a connection, so the app works with none.

On a phone it also records: start a capture before a meeting, put the phone
down, and the recording keeps running in the background. The transcript is
turned into a structured Markdown note on the device itself.
